# Baixador MP3-MP4

Script em batch (\Baixar.bat\) para descarregar áudio e vídeo usando \yt-dlp\ e \fmpeg\.

## Requisitos locais
Coloque os seguintes ficheiros na mesma pasta do \Baixar.bat\ (não incluídos no repositório):
- \yt-dlp.exe\
- \fmpeg.exe\

## Como usar
Execute \Baixar.bat\ no Windows e siga as instruções no terminal. Os ficheiros descarregados são guardados na pasta \Downloads/\.
